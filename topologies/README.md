# Topologies

Installable OMP topologies in this repository. When topologies exist,
names, versions, and descriptions below are taken verbatim from each
topology's `topology.yml` manifest. Install instructions are in the
[root README](../README.md#quick-start).

## No topologies yet

This index is currently empty. The repository provides the installer
and core tooling; topologies will be introduced separately, each
through its own pull request. As each topology lands, it is added here
with the version and description from its manifest and a link to its
documentation.

To propose a topology, see
[CONTRIBUTING.md](../CONTRIBUTING.md).
